# Pydah Universal Portal Switcher - Integration Guide (CDN)The **Pydah Universal Portal Switcher** is a floating widget packaged as a lightweight, zero-dependency CDN script. It allows authenticated users in any Pydah portal (Fee Management, HRMS, SDMS, Transport, Hostel, Academics, EMS, Admissions) to seamlessly switch between their permitted portals with one click.---## 🌟 Key Capabilities- **1-Line Embed**: Import via a single `<script>` tag.- **Pure Web Component (Shadow DOM)**: 100% style-isolated. It will never conflict with Bootstrap, Tailwind, Material UI, or custom CSS in the host application.- **Cross-Portal Permission Continuity**: When redirected from CRM or between portals, the widget automatically carries and persists the user's complete list of authorized portals in `localStorage`.- **Live Permission Discovery**: If a user logs into a portal directly, the widget automatically contacts the CRM Auth Gateway to verify and discover their allowed portals across all campus databases.- **Draggable Floating Button**: Users can drag the floating button anywhere on the screen so it never covers buttons or table rows. The position is remembered automatically.- **Real-Time Search**: Instant filtering across all permitted portals.---## 🚀 1. Quick Start (HTML / Index.html)Add this script tag right before the closing `</body>` tag of your application's `index.html`:```html<!-- Pydah Universal Portal Switcher CDN --><script   src="https://crm.pydah.edu.in/portal-switcher.js"   data-current-portal="fee-management"   async></script>```> 💡 **Important:** Replace `data-current-portal="fee-management"` with that specific app's ID (see [Portal IDs Reference](#-portal-ids-reference)).### For Local Development Testing:If you are developing or running portals locally on `localhost`:```html<script   src="http://localhost:5173/portal-switcher.js"   data-current-portal="fee-management"  data-api-base-url="http://localhost:8000"></script>```---## ⚛️ 2. Automatically render the floating switcher button.### Option B: Programmatic Initialization via JavaScript (App.jsx / AuthProvider)If your application loads the user session asynchronously or uses
